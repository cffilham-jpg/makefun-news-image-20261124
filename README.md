## Run

```sh
python3 main.py
# or: MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Writes `entry.png` (1024x1024, under 1 MiB) to `$MAKEFUN_OUTPUT_DIR`
(default `out`). Standard library only, no network, byte-identical on
repeat runs.
